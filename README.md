# JobTrack — Placement Application Tracker

JobTrack is a web-based placement application tracker that helps students organize and monitor their job and internship applications in one place.

## Features

* Add job and internship applications
* Track application status
* Record application and deadline dates
* Add notes for each application
* Search applications by company or role
* Filter applications by status
* Edit existing applications
* Delete applications
* Dashboard with application statistics
* Data persistence using browser Local Storage
* Responsive design for different screen sizes

## Application Status

JobTrack currently supports:

* Applied
* Online Test
* Interview
* Selected
* Rejected

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

## How It Works

1. Add a company and job role.
2. Enter the application date and deadline.
3. Select the current application status.
4. Add notes if required.
5. Track all applications from the dashboard.
6. Search, filter, edit, or delete applications whenever needed.
